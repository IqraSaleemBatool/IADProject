
# IvoryHaya Database

This folder contains the complete SQL database script for the **IvoryHaya Online Abaya Store** web application.

The database is responsible for storing and managing the application's users, roles, products, categories, shopping carts, orders, and order details.

---

## Database Management System

The project uses:

- **Microsoft SQL Server**
- **T-SQL (Transact-SQL)**
